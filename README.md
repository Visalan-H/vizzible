# DevHeat

**One link for all your coding activity.**

You've got a GitHub streak, a Codeforces rating, and a LeetCode grind — spread across three different profiles nobody's going to click through. DevHeat puts them on one page, one link, one heatmap.

Sign in with GitHub, drop in your Codeforces and LeetCode usernames, and get `devheat.app/u/you` — a shareable, resume-ready snapshot of everything you've built and solved this year. Drop it in your GitHub bio, your resume, your LinkedIn.

## Why it's actually useful

- **See it all at once.** Toggle between a combined view and each platform individually — commits next to contest submissions next to solved problems.
- **Always fast.** Your page never makes a visitor wait on three different APIs — it's cached, and refreshes itself quietly in the background.
- **Free, no fluff.** No signup wall to view a profile, no ads, no premium tier holding your own data hostage.

## Built with

React · Express · MongoDB · GitHub OAuth — deployed on Vercel.

## Status

Early build — GitHub, Codeforces, and LeetCode heatmaps are live. More platforms may follow if the demand's there.
